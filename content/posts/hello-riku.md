# Hello, Riku blog：從一篇 Markdown 開始

> 這是版型示範文章，不代表作者的經歷或觀點；可以自由改寫或刪除。

## 為什麼用 Markdown

文章保留為純文字，內容就能獨立於網站外觀。換字體、配色或閱讀版型時，不必重寫文章。

## 放一段程式碼

```ts
const author: string = 'Riku'
const greeting = (name: string): string => `Hello, ${name}!`
console.log(greeting(author))
```

## 下一篇文章

在 `content/posts` 建立新的 Markdown 檔案，填入標題、日期、摘要、分類與標籤，即可出現在首頁、搜尋與 RSS 中。

### 小小的寫作流程

1. 先記錄想解決的問題。
2. 留下過程與範例。
3. 整理結果，再發布文章。
